# SeatSprint – Ticket Booking System

A production‑grade movie/event ticket booking platform built with Django REST Framework, React, MySQL, Redis, Celery, and WebSockets.

## Quick Start

1. Clone the repository.
2. Copy `.env.example` to `.env`.
3. Run `docker-compose up --build`.
4. Backend: http://localhost:8000, Frontend: http://localhost:3000, Swagger: http://localhost:8000/api/v1/docs/
